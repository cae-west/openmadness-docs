## Project Background

[**Openmadness**](https://github.com/Technical-writing-mentorship-program/Openmadness) is an fictional open-source project developed by the [Technical Writing Mentorship Program](https://technicalwritingmp.com) (TWMP) as an assignment prompt for students to demonstrate practical documentation experience.

## Purpose
This documentation serves as guide to using the fictional Openmadness Javascript library and a demonstration of professional technical writing practices.

## Team Info
This documentation was created by the students of the TWMP as a collaborative project.
